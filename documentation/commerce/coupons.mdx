On your aasaan store, you can create discount coupons for special sales like festivals and end of season sales.   

<Note>These coupons will apply to your entire store. Here is how you do it.</Note>

---

<Tabs>
  <Tab title="Steps">

Go to your aasaan desktop admin panel and click on **Coupons** from the sidebar.

## Coupon Details
<Tabs>

## Coupon Scope  
  <Tabs>
    <Tab title="Steps">

      Choose the scope of the coupon. You need to decide whether the coupon applies to **specific categories**, **specific products**, or the customer's **entire order**.  
      In this guide, we will create a coupon for the **Entire Order**.
    </Tab>
    <Tab title="Screenshot">
      <Frame>
        <img src="https://cdn.lightbooks-dev.io/docs/coupons/coupons-07.png" />
      </Frame>
    </Tab>
  </Tabs>
  <AccordionGroup>

    <Accordion title="Entire Order Coupons">
      <Tabs>
        <Tab title="Steps">

          - Go to **Admin Panel → Marketing → Coupons → + New Coupon**
          - Enter **Coupon Name, Code, Description**
          - Select **Entire Order** as coupon type
          - Choose discount type: **Percentage** or **Fixed Amount**
          - Enter discount value (Example: `10` for 10% off)
          - (Optional) Set **Minimum / Maximum Cart Value**
          - (Optional) Add **Usage Limits** (per customer / total)
          - Add **Start & End Date**
          - Click **Save & Activate**

        </Tab>
      </Tabs>
    </Accordion>

    <Accordion title="Buy X Get Y">
      <Tabs>
        <Tab title="Steps">

          - Go to **Admin Panel → Marketing → Coupons → + New Coupon**
          - Enter basic details: name, code, description
          - Select **Buy X Get Y** as coupon type
          - Select products customer must buy (X)
          - Select products customer will get (Y)
          - Choose discount type: **Free Product / % Off / Fixed Discount**
          - (Optional) Add conditions like min quantity or max gifts
          - Add validity dates and usage limits if required
          - Save & activate the coupon

        </Tab>
      </Tabs>
    </Accordion>

    <Accordion title="Specific Products">
      <Tabs>
        <Tab title="Steps">

          - Go to **Marketing → Coupons → + New Coupon**
          - Enter coupon name, code, description
          - Select **Specific Products** as coupon type
          - Select eligible products
          - Choose discount type: % or fixed
          - Enter discount value (Example: `15` for 15% off)
          - (Optional) Set usage conditions (quantity, limit per customer, etc.)
          - Add validity and usage limit if required
          - Save & activate

        </Tab>
      </Tabs>
    </Accordion>

    <Accordion title="Specific Categories">
      <Tabs>
        <Tab title="Steps">

          - Go to **Marketing → Coupons → + New Coupon**
          - Enter basic details (name, code, description)
          - Select **Specific Categories** as coupon type
          - Choose one or more categories
          - Choose discount type: % or fixed
          - Enter discount value (Example: `20` for 20% off)
          - (Optional) Add min/max cart or item rules
          - Add validity & usage limits
          - Save & activate

        </Tab>
      </Tabs>
    </Accordion>

    <Accordion title="Free Shipping">
      <Tabs>
        <Tab title="Steps">

          - Go to **Admin Panel → Marketing → Coupons → + New Coupon**
          - Enter name, code, description (Example: `FREESHIP`)
          - Select **Free Shipping** as coupon type
          - (Optional) Select countries (all or specific)
          - (Optional) Add rules (min purchase, exclude high shipping rates, etc.)
          - (Optional) Set customer eligibility (all, segment, specific)
          - (Optional) Add usage limits (e.g., first 100 orders)
          - Add validity dates
          - Save & activate

        </Tab>
      </Tabs>
    </Accordion>

</AccordionGroup>
