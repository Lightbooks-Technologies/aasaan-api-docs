---
title: "WhatsApp Manager"
description: "Create templates, build lists, run campaigns, manage contacts, and chat with customers"
---

<p>WhatsApp Manager allows you to create message templates, build customer lists, send bulk or scheduled WhatsApp campaigns, and manage customer conversations — including sending products directly inside chat.</p>

---

## Workflow Overview
<p>1. Create and get approval for message templates<br/>
2. Build audience lists<br/>
3. Send campaigns (immediately or scheduled)<br/>
4. View and manage contacts<br/>
5. Chat with customers and send products in real time</p>

---

## WhatsApp Manager Sections

<AccordionGroup>

  <Accordion title="1. Templates">
    <Tabs>
        <Tab title="Steps">

            - Go to **Admin Panel → WhatsApp Manager → Templates**
            - Click **Create Template**
            - Select a template type (Text, Media, Buttons, etc.)
            - Enter template name, language, category, and message content
            - Submit template for **Meta approval** (required before use)

        </Tab>
    </Tabs>
  </Accordion>

  <Accordion title="2. Lists (Audience)">
    <Tabs>
        <Tab title="Steps">

            - Open **WhatsApp Manager → Lists**
            - Create a new list by uploading CSV or adding contacts manually
            - Map fields (phone number, name, tags, etc.)
            - Save list — it will be available for campaign use

        </Tab>
    </Tabs>
  </Accordion>

  <Accordion title="3. Campaigns">
    <Tabs>
        <Tab title="Steps">

            - Go to **Campaigns → Create Campaign**
            - Select an approved template and choose the audience list
            - Enter campaign name, template variables, sender info, etc.
            - Choose to **Send Now** or **Schedule** for later

        </Tab>
    </Tabs>
  </Accordion>

  <Accordion title="4. Contacts">
    <Tabs>
        <Tab title="Steps">

            - Go to **Contacts** to view uploaded or synced customer data
            - Search, filter, and segment contacts (tags, list, last message, etc.)
            - View customer profile: name, number, tags, campaign history, chat history

        </Tab>
    </Tabs>
  </Accordion>

  <Accordion title="5. Chats">
    <Tabs>
        <Tab title="Steps">

            - Open **Chats** to view incoming WhatsApp messages
            - Reply using text, images, PDFs, etc.
            - Send products directly from chat by browsing your catalog
            - Manage chat workflow: assign agent, add tags, mark resolved, etc.

        </Tab>
    </Tabs>
  </Accordion>

</AccordionGroup>
